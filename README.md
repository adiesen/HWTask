# HWTask
Task to obtain hardware information

## Prerequisites

Install the stable Rust toolchain using [rustup](https://rustup.rs/).
Rust 2024 edition requires Rust 1.85 or later. On Windows, the default MSVC
toolchain also requires Visual Studio Build Tools with the Desktop development
with C++ workload.

## Development

Run the application from the project root:

```sh
cargo run
```

The application opens a native dashboard window with CPU temperature, GPU usage,
memory usage, and a sensor readings table. The current sensor values are
simulated demo data, not readings from the machine's hardware.

```sh
cargo check                    # Check compilation
cargo test                     # Run tests
cargo fmt --check              # Check formatting
cargo clippy -- -D warnings    # Run lint checks
cargo build --release          # Build an optimized executable
```

The entry point is `src/main.rs`. Release builds are written to `target/release/`.
Commit the `Cargo.lock` file generated by Cargo to keep application builds
reproducible.
